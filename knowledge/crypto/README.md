# General crypto knowledge retention

Only reusable, evidence-gated techniques belong here. Never store flags,
credentials, live target secrets, or challenge write-up text. For each lesson,
record indicators, the cheapest deterministic check, finite caps, and the
verification relation. Challenge-specific code and transcripts stay in their
workspace or `solutions/<challenge_id>/`.

The active route catalog is [ctf_agent/playbooks.py](../../ctf_agent/playbooks.py)
and the benchmark policy is [benchmarks/crypto/README.md](../../benchmarks/crypto/README.md).
