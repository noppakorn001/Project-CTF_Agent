# 90DAY2 — duplicate-file triage

**Status:** `RESEARCH_ONLY`

เมื่อมีไฟล์จำนวนมาก ให้ hash แบบ chunk แล้วจัดกลุ่มตาม digest แทนการเปิดทีละไฟล์. ตรวจ
เฉพาะ groups ที่มี content ต่างกันจริง และอ้าง path/size/hash ใน timeline.

```bash
sha256sum -- * | sort -k1,1 | uniq -w64 -D
```

คำสั่งนี้เป็น triage เท่านั้น; verifier ต้องอ่าน bytes ของ candidate file และตรวจ format.
