# picoCTF 2025–2026 reusable lessons

This reference distills techniques from authorized challenge work already
captured in this repository. It deliberately omits flags, account data, and
target-specific secrets.

## Crypto / nonce and state reuse

Signal → two authenticated ciphertexts share an exact nonce or keystream
position, and the source exposes known plaintext → derive the stream prefix
from `P xor C`, then test the MAC construction's algebra (Poly1305 over
`2^130-5` for ChaCha20-Poly1305) with a declared carry/root cap → stop when the
nonce is unique, tags disagree, or the candidate fails a clean decrypt-and-
verify replay. Never reuse a packet from a different instance; keep the capture
and forged packet on the same session.

## Crypto / bounded modular leakage

Signal → a modular polynomial system is underdetermined but the coefficients
have an explicit smaller bound or a hash-chain relation → reduce the exact
system, use a bounded lattice/LLL route only after estimating dimension and
memory, and check every original equation plus the downstream key relation →
stop on rank mismatch, exceeded caps, or a candidate that does not reproduce
all supplied samples.

## Crypto / oracle trust boundary

Signal → a service refuses one secret ciphertext but decrypts arbitrary related
ciphertexts → first recover public parameters from supplied encryptions or
source, then make one multiplicative/additive transform and undo it exactly;
keep query counts capped and record the raw response → stop when the oracle
requires the protected input, the relation is not evidenced, or the recovered
value fails the downstream scheme replay. A candidate is not verified merely
because a caller supplied `reproduced=true`.

## Crypto / large interpolation

Signal → a text artifact contains a very large consecutive-point stream and
the challenge code constructs a dense Vandermonde matrix → preserve/hash the
full artifact, scan only a bounded prefix, and route to product-tree,
derivative-based fast finite-field interpolation; do not materialize an
`n × n` matrix or send the file to a model → stop and request a Sage/Galois or
other bounded numerical runtime when the fast solver is unavailable.

## Routing and verification regression

All 2025/2026 routes above require an independent replay relation: original
artifact hashes, exact parameters, bounded command/script, and a clean verifier
context. Platform submission remains a manual operator action. These lessons
are supported crypto-playbook routes, not permission to probe arbitrary hosts.
